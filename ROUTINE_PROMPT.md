# Prompts for the two daily routines

Create two scheduled routines in Claude Code (see SETUP.md step 6). Paste these exactly.

## Routine 1: "Records Office Short, slot 1", every day 6:00 AM
```
Daily run, slot 1. Follow CLAUDE.md in this repo exactly and make today's Slot 1 Short
(History, Geography or Technology), 60 to 70 seconds, from fresh trend and competitor research.
Verify every fact with two sources before scripting; if a topic fails a gate, pick another.
Upload it as set in config/settings.md, log it, write the run report, commit and push.
```

## Routine 2: "Records Office Short, slot 2", every day 6:20 AM
```
Daily run, slot 2. Follow CLAUDE.md in this repo exactly and make today's Slot 2 Short
(Finance, Geopolitics or Current Affairs), 60 to 70 seconds, from fresh trend and competitor research.
Verify every fact with two sources before scripting; if a topic fails a gate, pick another.
Upload it as set in config/settings.md, log it, write the run report, commit and push.
```

## Manual test prompt (use this first, in a normal Claude Code session)
```
Test run, slot 1. Follow CLAUDE.md and make one Short, but upload it as private
and stop after each stage to show me what you made (topic, sources, script, audio, video).
```
